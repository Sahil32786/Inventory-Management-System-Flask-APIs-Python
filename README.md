# Inventory Management System (Flask + SQLite + bootstrap)


## Requirements
- Python 3.8+
- pip

## Setup 
1. Create python project 
2. Clone or pest files as it is
3. Install dependencies with : "pip install -r requirements.txt"
4. Run python file with : "python app.py
5. Open URL : "http://127.0.0.1:5000"
6. Ready to go
